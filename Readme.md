# TUGAS INDIVIDU — LOVELY BAKERY

## Deskripsi

Tugas individu merupakan pembuatan mockup website Lovely Bakery yang bertema toko roti. Website dirancang dengan tampilan yang sederhana dan menarik untuk menampilkan informasi serta produk roti yang ditawarkan.

Desain menggunakan kombinasi warna cream, peach, dan cokelat untuk memberikan kesan hangat dan sesuai dengan identitas toko roti. Tampilan dibuat dalam dua ukuran, yaitu desktop dan mobile, agar desain dapat menyesuaikan perangkat yang digunakan.

## Struktur Halaman

- **Halaman Utama**
- **Halaman Login**
- **Halaman Registrasi**
- **Halaman Katalog Produk**
- **Halaman Profil**

## Penerapan Desain

1. Menggunakan warna cream, peach, dan cokelat sebagai identitas visual.
2. Menggunakan gambar roti sebagai elemen utama website.
3. Menyusun tampilan halaman secara konsisten.
4. Menggunakan elemen tombol dan formulir dengan gaya yang seragam.
5. Membuat mockup dalam ukuran desktop dan mobile.
6. Menyesuaikan susunan elemen agar tetap nyaman dilihat pada layar smartphone.

# TUGAS kelompok/individu/individu — DESIGN SYSTEM LOVELY BAKERY

## Deskripsi

Tugas kelompok/individu/individu merupakan pembuatan Design System untuk website Lovely Bakery. Design System berfungsi sebagai panduan desain agar seluruh halaman website memiliki tampilan yang konsisten.

Design System disusun berdasarkan identitas visual Lovely Bakery dan mencakup warna, tipografi, tombol, card produk, form controls, serta spacing dan layout.

## Penerapan Design System

### 1. Color Palette

Warna yang digunakan dalam desain meliputi:

- Cream: `#F8F0E5`
- Peach: `#F8CDAE`
- Brown: `#8A5A3B`

Warna cream digunakan sebagai warna latar, peach sebagai warna pendukung, dan cokelat sebagai warna utama untuk tombol serta elemen yang perlu ditonjolkan.

### 2. Typography

Tipografi digunakan untuk membedakan judul, subjudul, dan teks isi.

- Heading: Playfair Display, 24–32 px.
- Subheading: Poppins, 16–20 px.
- Body Text: Poppins, 12–16 px.

Penggunaan tipografi yang konsisten membantu membuat informasi lebih mudah dibaca.

### 3. Button Style

Button Style berisi panduan tampilan tombol yang digunakan pada website.

- Tombol utama menggunakan latar cokelat dengan teks putih.
- Tombol sekunder menggunakan latar putih dengan garis tepi cokelat.
- Ukuran, bentuk, dan jarak tombol dibuat konsisten.

Contoh tombol yang digunakan adalah Shop Now dan View Details.

### 4. Card Style

Card Style digunakan sebagai panduan untuk komponen kartu produk. Setiap kartu berisi gambar produk, nama produk, harga, dan tombol.

Contoh produk yang ditampilkan adalah Sourdough Bread dan Butter Croissant. Bentuk kartu dan ukuran gambar dibuat seragam agar tampilan katalog lebih rapi.

### 5. Form Controls

Form Controls merupakan panduan elemen formulir yang digunakan pada halaman login dan registrasi.

Komponen ini mencakup kolom email dan password. Bentuk input, garis tepi, ukuran, dan jarak antarelemen dibuat konsisten.

### 6. Spacing & Layout

Spacing & Layout digunakan untuk mengatur jarak dan susunan elemen dalam website.

- Jarak antarelemen: 8–24 px.
- Padding kartu: 16 px.
- Jarak antarseksi: 40–64 px.
- Desktop menggunakan layout beberapa kolom.
- Mobile menyesuaikan susunan elemen dengan lebar layar.

Panduan ini membantu menjaga kerapian dan konsistensi tampilan seluruh halaman Lovely Bakery.

## STUDI KASUS — PORTAL AKADEMIK UNIVERSITAS BARBIE

### Deskripsi

Studi kasus ini merupakan pengembangan desain website Portal Akademik Universitas Barbie sebagai layanan pendidikan digital. Website dirancang untuk menampilkan informasi akademik dan memudahkan mahasiswa dalam mengakses berbagai layanan perkuliahan.

Desain menggunakan kombinasi warna pink, ungu, dan putih untuk menciptakan tampilan yang menarik. Pengembangan desain memperhatikan tata letak, hierarki visual, penggunaan card, tombol, serta susunan informasi agar mudah dipahami oleh pengguna.

### Struktur Halaman

- **Header**
- **Navigasi**
- **Sidebar**
- **Dashboard**
- **Informasi Akademik**
- **Layanan Mahasiswa**
- **Footer**

### Penerapan Desain

1. Menggunakan kombinasi warna pink, ungu, dan putih.
2. Menampilkan logo dan identitas Universitas Barbie pada bagian header.
3. Menggunakan navigasi dan sidebar untuk mengatur akses informasi.
4. Menyusun informasi akademik menggunakan card.
5. Menonjolkan tombol Lihat Jadwal Kuliah sebagai akses menuju informasi jadwal.
6. Menggunakan gambar sebagai pendukung informasi akademik.s
7. Menyusun layanan mahasiswa dalam bentuk tombol agar mudah dikenali.
